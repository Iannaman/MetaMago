# Security
Non allegare documenti reali, credenziali, token o nominativi privati alle issue pubbliche. Per i problemi di sicurezza usa la funzione di segnalazione privata GitHub, se abilitata, o chiedi al maintainer un canale privato senza divulgare dettagli sensibili. Il programma non è firmato con un certificato di code signing; verifica i sorgenti e SHA256SUMS prima dell'uso.
