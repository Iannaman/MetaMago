# Audit Edition — MetaMago 1.10.0

## Confronto
Apri Confronta documenti (Alt+Maiusc+9). Seleziona due file Office supportati, anche di formati differenti, oppure usa l'originale già aperto e l'ultima copia verificata dell'editor. Il confronto non modifica i file e non confronta il contenuto, le proprietà personalizzate estranee al Mark o l'identità binaria. Confronta le 17 proprietà standard come stringhe originali, lo stato finale e lo stato/versione/edizione del Mark riconosciuto. Un Mark in conflitto è non conclusivo. Mostra solo differenze è un filtro visivo: l'esportazione comprende tutte le righe. I riferimenti ai file selezionati rimangono in memoria finché non si svuota il confronto o si chiude/ricarica l'app.

## Report
- Confronto: nomi dei documenti e valori A/B.
- Inspector: proprietà originali, punteggio, controlli, copertura XML, indizi privacy e modello attualmente selezionato.
- Copia verificata: nome originale e copia, valori precedenti e modifiche verificate dal motore di riscrittura, incluse azioni sul Mark e stato finale.
- Batch: anteprima (proposte, non eseguite) oppure esito elaborazione (stati per documento e valori proposti, con stato che indica se la copia è stata verificata). File esclusi e invariati inclusi come stati; nessun report di esito se il batch è annullato o la generazione ZIP fallisce.

Premi Report CSV oppure Report HTML, conferma l'avviso di riservatezza. CSV UTF-8 con BOM, separatore punto e virgola e celle quotate; valori che sembrano formule vengono prefissati con apostrofo per ridurre il rischio di interpretazione come formula in Excel. L'apostrofo può essere visibile in altri lettori; i dati originali del documento non cambiano. HTML statico con escaping dei valori, CSP restrittiva, nessuno script o risorsa esterna; stampabile dal browser.

I report possono contenere nomi, proprietà riservate e percorsi tecnici nei messaggi di errore. Non condividere senza autorizzazione. Non sono firmati, non certificano conformità, integrità completa o autenticità, non sono un registro immodificabile né una prova che il download sia stato salvato sul disco. Nessuna cronologia persistente, invio a server o report automatico. I file esportati sono responsabilità dell'utente e vanno gestiti secondo le procedure dell'organizzazione.
